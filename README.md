# 专注时刻 · Focus Timer

一个轻量的浏览器专注计时器，帮助你把注意力留给眼前的事情。

## 功能

- 25 分钟专注、5 分钟短休息和 15 分钟长休息
- 暂停、继续、重置和进度展示
- 根据实际时间计算，切换标签页后仍能正确更新
- 记录当天完成的专注次数，数据仅保存在当前浏览器
- 适配手机与桌面，无需依赖或构建步骤

## 使用

下载项目并在浏览器打开 `index.html`。选择模式，点击开始即可。计时结束后页面会显示提示；今日记录可手动清除。

## 技术

HTML、CSS 和原生 JavaScript。浏览器关闭后不会恢复未完成的计时；今日完成次数保存在 localStorage 中。
