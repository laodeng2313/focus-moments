# 专注时刻 · Focus Moments

A simple, privacy-friendly focus timer that runs entirely in your browser. No account, installation, or build step required.

**[在线体验 / Try the live demo](https://laodeng2313.github.io/focus-moments/)**

## 功能 / Features

- 25-minute focus sessions, 5-minute short breaks, and 15-minute long breaks
- Pause, resume, reset, and track progress
- Time is calculated from the clock, so switching tabs won't make the timer drift
- Daily focus count stored locally in your browser
- Responsive layout for desktop and mobile

一个轻量的浏览器专注计时器。支持专注、短休息和长休息，记录当天完成的专注次数；数据保存在当前浏览器中。

## 使用 / Getting started

Open the [live demo](https://laodeng2313.github.io/focus-moments/) or download the repository and open `index.html` in a modern browser. Choose a mode and press Start. Keep the page open while the timer runs.

打开[在线体验](https://laodeng2313.github.io/focus-moments/)，或下载项目并用浏览器打开 `index.html`。选择模式，点击开始即可。

## Notes

The completion message appears in the page; the app does not currently send notifications. An unfinished timer is not restored after the page is closed. The daily count is saved in localStorage and can be cleared in the app.

## Built with

HTML, CSS and vanilla JavaScript; no dependencies.
